DMIS 5.3 Post-Processor & Intermediate Language Architecture

1. Executive Summary & Objective

This document outlines the architecture, data models, and implementation strategy for converting JSON-based CMM inspection paths (generated by the Hi-rEV SmartFitSystems path planning engine) into standardized ANSI/DMIS 5.3 (Dimensional Measuring Interface Standard) inspection programs.

The system uses a decoupled, two-stage conversion pipeline:

  1. Front-End / Path Ingestion: Translates application path data (PathExportDTO or live PathManager probe paths) into an open CMM Intermediate Representation (IR) / Intermediate Language.
  2. Back-End / Post-Processor: Translates the Intermediate Representation into compliant, production-ready DMIS 5.3 code, with support for indexable probe heads (Renishaw PH10), machine kinematics, calibration references, approach/retract moves, and feature measurements.

2. Standard Reference Analysis (ANSI/DMIS 5.3)

Based on the official standard manual ANSI/DMIS 105.3-2016 (ANSI_DMIS_5_3_Final.pdf):

2.1 Core Statements & Syntax Rules

  • Program Header & File Initialization:
    • DMISMN/'<program_name>',05.3 - Required starting statement declaring DMIS version 5.3.
    • FILNAM/'<file_name>',05.3 - Specifies part program name and version.
    • DVIFRM/05.3 - Version format verification.
    • UNITS/MM,ANGDEC (or INCH,ANGDEC) - Dimensional units and angular units (decimal degrees).
    • DECPL/ALL,4 - Defines numeric output precision (4 decimal places standard in metrology).
    • WKPLAN/XYPLAN - Working coordinate plane definition.
    • PRCOMP/ON - Enables probe tip radius compensation along approach vector.
    • MODE/AUTO,PROG,MAN - Sets execution mode to automatic program control.

2.2 Machine Parameters & Sensor Settings

  • Feedrates:
    • FEDRAT/POSVEL,CART,<traverse_speed_mm_s> - Traverse / positioning velocity between clearance points.
    • FEDRAT/MESVEL,CART,<touch_speed_mm_s> - Measuring velocity during contact touch.
  • Sensor Clearances:
    • SNSET/APPRCH,<distance_mm> - Safe approach distance before touch.
    • SNSET/RETRCT,<distance_mm> - Retract distance after touch.
    • SNSET/SEARCH,<distance_mm> - Search distance beyond nominal surface.
    • SNSET/CLRSRF,<distance_mm> - Clearance surface offset distance.

2.3 Machine, Wrist & Tool Kinematics (Section 5.4.4, Clause 6, Annex A.29)

  • Sensor Reference Mount (SNSMNT):
    • SNSMNT/XVEC,1,0,0,ZVEC,0,0,1,MNTLEN,0,0,0
    • Defines the sensor coordinate system relative to the CMM machine coordinate system (MCS).
  • Indexable Wrist (WRIST):
    • Models motorized heads such as the Renishaw PH10M: dmis SW(PH10)=WRIST/ROTCEN,0,0,-5,0,0,1,0,1,0,ANGLE,'RotAngle',-180,180,7.5,$ ROTCEN,0,0,-25,1,0,0,0,0,-1,ANGLE,'TiltAngle',0,105,7.5,$ MNTLEN,0,0,-45,'Renishaw','PH10M',1
    • RotAngle (Axis B): Yaw / Azimuth rotation in XY plane (-180 deg to +180 deg in 7.5 deg increments).
    • TiltAngle (Axis A): Pitch / Inclination rotation from +Z (0 deg to 105 deg in 7.5 deg increments).
  • Stylus & Extension Definitions (EXTENS, SENSOR):
    • SX(EXT50)=EXTENS/0,0,-50 (50mm extension)
    • SS(TP20)=SENSOR/PROBE,0,0,-20,0,0,-1,2,SPHERE (2mm ball stylus)
  • Sensor Assembly & Selection (SNSGRP, SNSDEF, SNSLCT):
    • SGS(Tool1)=SNSGRP/BUILD,SX(EXT50),SS(TP20)
    • S(Probe1)=SNSDEF/BUILD,SW(PH10),SGS(Tool1)
    • SNSLCT/S(Probe1)
    • Re-orienting the wrist for a feature:
      • Standard wrist angle syntax: SNSLCT/S(Probe1),SW(PH10),'RotAngle',<AngleB>,'TiltAngle',<AngleA>
      • HeadCS syntax: SNSLCT/S(Probe1),HEADCS,<AngleA>,<AngleB>

2.4 Motion & Measurement Sequences

  • Rapid / Clearance Moves:
    • GOTO/CART,<X>,<Y>,<Z>
  • Point Feature Definition & Touch Probing:
    • Standard DMIS 5.3 measurement block: dmis F(PT_001)=FEAT/POINT,CART,<X>,<Y>,<Z>,<I>,<J>,<K> MEAS/POINT,F(PT_001),1 PTMEAS/CART,<X>,<Y>,<Z>,<I>,<J>,<K> ENDMES
    • <X>, <Y>, <Z>: Target surface touch point coordinate.
    • , <J>, <K>: Unit normal vector pointing away from the measured surface toward the probe tip.
  • Program Termination:
    • ENDFIL - Required standard terminator for DMIS programs.

3. Intermediate Representation (IR) Architecture

Rather than hardcoding DMIS generation directly into the path planning classes, we define a CMM Intermediate Representation:

PathPlanningEngine / PathExportDTO | v [ CmmIntermediateModel ] |-- CmmProgram (Metadata, units, author, timestamp) |-- CmmMachineDefinition (Kinematics, limits, home) |-- CmmWristDefinition (Head parameters, axes A & B) |-- CmmToolDefinition (Stylus length, tip radius, extensions) +-- CmmSequence (Ordered commands per color path / feature) |-- CmmCommentCommand |-- CmmParameterSetCommand (Feeds, clearances) |-- CmmSensorOrientationCommand (A, B angles) |-- CmmMotionCommand (Rapid, Traverse, Clearance) +-- CmmTouchPointCommand (Contact X,Y,Z, Normal I,J,K, Feature ID) | v [ DMISPostProcessor ] | v ANSI/DMIS 5.3 Program (.dmi / .dmis)

Benefits of the Intermediate Representation:

  1. Extensibility: Allows supporting additional CMM controllers in the future (e.g., PC-DMIS, Zeiss Calypso, Renishaw MODUS, G-Code) without altering path planning logic.
  2. Verification & Simulation: The IR can be inspected, validated, and optimized (e.g. eliminating redundant head rotations, validating kinematic limits) before code generation.
  3. Traceability: Retains face index, color group, tool name, and CAD model associations throughout the post-processing pipeline.

4. Mapping Rules: JSON Paths -> Intermediate -> DMIS 5.3

JSON Path Point (PathPointExportDTO) Intermediate Command (CmmCommand) DMIS 5.3 Output
PointType == 'Start' or 'End' CmmMotionCommand (Clearance) GOTO/CART, X, Y, Z
PointType == 'Safe' or 'Bridge' or 'ShellWaypoint' CmmMotionCommand (Rapid/Traverse) GOTO/CART, X, Y, Z
PointType == 'Approach' CmmMotionCommand (Approach) GOTO/CART, X, Y, Z
PointType == 'Measurement' CmmTouchPointCommand F(name)=FEAT/POINT...\nMEAS/POINT,F(name),1\nPTMEAS/CART,X,Y,Z,I,J,K\nENDMES
HeadAngleA / HeadAngleB change CmmSensorOrientationCommand SNSLCT/S(tool),SW(PH10),'RotAngle',B,'TiltAngle',A
ToolName change CmmToolChangeCommand SNSLCT/S(tool)
