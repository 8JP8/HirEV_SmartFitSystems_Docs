Descrição detalhada

Custom equality comparer for Point3D objects that allows tolerance-based comparison. Useful for HashSet and Dictionary operations where floating-point precision requires fuzzy equality.

This comparer implements IEqualityComparer<Point3D> to provide:

  • Tolerance-based equality checking (1e-6 or 0.000001 units)
  • Consistent hash code generation for points within tolerance

The tolerance of 1e-6 (1 micrometer if units are mm) is suitable for most CAD applications. Points within this tolerance of each other are considered equal.

Hash code generation uses bit-shifting to combine coordinate hashes, ensuring good distribution.

bool HirEV_SmartFitSystemsApp.Modules.Point3DComparer.Equals ( Point3D? p1,
Point3D? p2 )

Determines whether two Point3D objects are equal within the defined tolerance.

Parâmetros
p1The first point to compare. Can be null.
p2The second point to compare. Can be null.
Retorna
true if the points are the same reference, both null, or within tolerance in all dimensions (X, Y, Z); false otherwise.

Comparison logic:

  1. Reference equality check (same object instance)
  2. Null checks (both null = equal, one null = not equal)
  3. Component-wise comparison with tolerance (|X1-X2| < tolerance AND |Y1-Y2| < tolerance AND |Z1-Z2| < tolerance)

◆ GetHashCode()

int HirEV_SmartFitSystemsApp.Modules.Point3DComparer.GetHashCode ( Point3D? p)

Generates a hash code for a Point3D based on quantized coordinates. Points within the tolerance will generate the same hash code.

Parâmetros
pThe point to generate a hash code for. Must not be null.
Retorna
An integer hash code combining the quantized X, Y, and Z coordinates. Uses bit-shifting (XOR with left shift) to combine individual coordinate hashes.

Hash code generation:

  1. Quantizes each coordinate by rounding (coordinate / tolerance)
  2. Gets hash code for each quantized value
  3. Combines using XOR with bit-shifting: hashX ^ (hashY << 1) ^ (hashZ << 2)

This ensures:

  • Points within tolerance have the same quantized coordinates
  • Same quantized coordinates produce the same hash code
  • Good distribution of hash codes across buckets
  • Satisfies contract: Equals(p1, p2) implies GetHashCode(p1) == GetHashCode(p2)
