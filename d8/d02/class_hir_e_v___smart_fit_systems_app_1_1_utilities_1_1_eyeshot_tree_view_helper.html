Descrição detalhada

Manages the hierarchical TreeView displaying extracted CAD faces and holes organized by color.

Performance Optimization: Employs an advanced UI node caching strategy that pre-builds the entire TreeView hierarchy in memory. This enables near-instantaneous filtering operations based on visibility and exterior/interior status without recreating UI elements.

TreeView Structure:

Root
├── Color Group (e.g., "Blue")
│ ├── Faces (12)
│ │ ├── Face #1 - Planar (Exterior)
│ │ ├── Face #2 - Cylindrical (Interior)
│ │ └── ...
│ └── Holes (3)
│ ├── Hole M6x1.0 - Ø6.00mm
│ └── ...
└── ...

Key Features:

  • Color-based organization with face/hole counts
  • Cached hierarchy for fast filtering (exterior/interior, visibility toggles)
  • Selection synchronization with 3D viewport
  • Localized labels (EN/PT support)

◆ InvalidateCache()

void HirEV_SmartFitSystemsApp.Utilities.EyeshotTreeViewHelper.InvalidateCache ( )

Invalidates the internal cache, forcing a full rebuild on the next PopulateTreeView() call.

Call this method whenever:

  • Faces are re-extracted from the CAD model
  • Holes are detected or re-detected
  • The data source structure changes (e.g., color reassignment)

The cache will be automatically rebuilt the next time PopulateTreeView() is called.

◆ SelectFaceInTree()

void HirEV_SmartFitSystemsApp.Utilities.EyeshotTreeViewHelper.SelectFaceInTree ( CADFace face)

Selects and scrolls to a specific CADFace in the TreeView.

Parâmetros
faceThe CADFace to select

Search strategy:

  1. Iterates through color group nodes
  2. Finds the "Faces" sub-group within the color
  3. Searches for a face node matching EntityIndex and FaceIndex
  4. Expands parent nodes and selects the face
  5. Scrolls the selected node into view

Does nothing if face is null or not found in the tree.
