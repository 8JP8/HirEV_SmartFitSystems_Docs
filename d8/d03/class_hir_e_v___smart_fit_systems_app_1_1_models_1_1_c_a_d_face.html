Descrição detalhada

Data model representing a single face extracted from a 3D CAD model. Contains geometric, topological, and classification information for the face.

This class serves as the primary data transfer object for face information between extraction, analysis, and visualization stages. Each face is uniquely identified by FaceGlobalIndex and contains:

  • Geometric data (control points, key points, area)
  • Classification data (face type, geometric info)
  • Topological data (entity/face indices for parent Brep)
  • Display data (color)
  • State flags (exterior, ignored)

Faces are extracted by FaceExtractor and may be grouped into holes by HoleDetector.
