Descrição detalhada

Manages session file creation, saving, and loading for the application. Each application launch generates a new timestamped session file in the SaveFiles folder. A maximum of MaxSessionFiles files are retained; the oldest are pruned automatically. Loading a saved session points the active session at that file — all subsequent saves update it in-place.
