HirEV SmartFitSystems

Introduction

Welcome to the documentation for the HirEV SmartFitSystems application, a project developed by SARKKIS Robotics as an integral part of the Hi-rEV initiative. The Hi-rEV project aims to drive the technological modernization of the electric vehicle production industry.

This application provides a sophisticated solution for the automatic quality control of machined parts. It leverages 3D CAD models to streamline and automate metrological inspection, ensuring that manufactured components adhere strictly to their design specifications.

The broader Hi-rEV project encompasses two primary goals:

  1. Reverse Engineering: Generating precise 3D models of real-world components using intelligent sensors (dense scanning, contact probes) when a CAD model is not available.
  2. Automated Inspection Planning: Converting existing CAD models into safe and efficient measurement paths for metrology equipment to verify the geometry of machined parts.

This application, HirEV_SmartFitSystemsApp, is dedicated to the second objective, providing a powerful platform for CAD-based inspection planning and execution.

Key Features

The HirEV SmartFitSystems application is equipped with a range of advanced features to facilitate a seamless workflow from CAD model to quality inspection:

  • CAD-Based Measurement Planning: The core of the application is its ability to interpret 3D CAD models (STEP files) and automatically generate efficient and collision-free inspection paths for CMM probes and other metrology tools.
  • Color-Coded Tolerancing: A key innovation is the use of surface colors within the CAD model to define manufacturing tolerances. This allows for the rapid assignment of inspection requirements to large groups of similar faces, optimizing both measurement planning and the logic for tool changes.
  • Advanced 3D Visualization: Powered by the devDept.Eyeshot professional CAD control, the application provides high-performance 3D rendering and interaction. Users can load, pan, zoom, rotate, and select faces and features on complex 3D models with ease.
  • Automatic Face and Feature Extraction: The application intelligently processes the geometry of a loaded model to automatically extract all constituent faces. It further analyzes this data to detect and classify geometric features, such as holes, and groups them by color for simplified processing.
  • Path Generation and Simulation: Using sophisticated heuristic algorithms, the system generates optimized measurement paths. These paths can be visualized directly on the 3D model and simulated in real-time, providing a complete preview of the inspection routine, including tool movements.
  • Dynamic Tool and Camera System: The simulation environment is not limited to default probes. It fully supports the loading and visualization of custom 3D models for measurement tools. A robust camera-following system ensures the tool is always in focus during simulation, even for complex custom models.

Current Application Capabilities

The current application workflow expands those core features with:

  • CAD and Feature Processing: Load CAD parts into the Eyeshot workspace, extract faces, vertices, colors, normals, holes, and feature dimensions, and work with multiple parts and independent part origins.
  • Hole Detection: Detect cylindrical and conical hole features, including split, bridged, and single cylindrical faces.
  • Probe Path Planning: Generate point-by-point probing paths with approach, measurement, ascent, descent, and bridge waypoints, ordered by color or by part with proximity-based optimization.
  • Scanner Path Planning: Configure scanner profiles from ScannerConfigurations.xml and generate scanner poses using FOV, standoff, overlap, hole-scan, and coverage settings.
  • Shell and Collision Support: Generate offset shell meshes, use SDF and Marching Cubes planning envelopes, cache shell data in sessions, and validate or reroute path segments.
  • Simulation and Visualization: Simulate probe and scanner motion, control simulation speed, rotate tool models toward surface normals, follow the active tool with the camera, and inspect section views.
  • Sessions and Export: Save and load sessions with loaded parts, extracted faces, ignored items, paths, shell cache data, and UI state; export JSON/XML inspection data by color, tool, control point, or measurement point.

Quick Start Guide

Requirements

  • Windows 10/11 x64.
  • .NET 8 SDK or Runtime.
  • devDept Eyeshot Ultimate license.
  • Access to the SARKKIS proprietary NuGet packages used by the project.

Build

dotnet build HirEV_SmartFitSystemsApp.sln -c Release

Run

dotnet run --project HirEV_SmartFitSystemsApp/HirEV_SmartFitSystemsApp.csproj

Key Configuration Files

  • HirEV_SmartFitSystemsApp/App.config: language, CMM mode, scanner parameters, path planning, shell generation, simulation, export, and UI defaults.
  • HirEV_SmartFitSystemsApp/ScannerConfigurations.xml: scanner presets, FOV data, standoff ranges, 3D model paths, and sensor transforms.
  • HirEV_SmartFitSystemsApp/MeasuringToolByColor.xml: measuring tool assignment by extracted face color.
  • HirEV_SmartFitSystemsApp/ColorTolerances.xml: color matching tolerances.
  • ProtectedConfig.dat: encrypted machine and sensitive settings generated at runtime.

Typical Workflow

  1. Load one or more CAD parts.
  2. Extract faces and holes.
  3. Assign or confirm tool or scanner configuration.
  4. Generate probe or scanner paths.
  5. Review paths, shell, points, and section views.
  6. Simulate the sequence and verify scanner coverage or probe movement.
  7. Edit paths or move parts if required.
  8. Load saved sessions to avoid repeated path generation and manual edits.

Technical Highlights

  • Platform: Built on the modern .NET 8 framework using C# and Windows Presentation Foundation (WPF) for a responsive user interface.
  • Architecture: Employs the Model-View-ViewModel (MVVM) design pattern for a clean separation of concerns, with MainViewModel serving as the core of the application logic.
  • 3D Engine: Leverages the powerful devDept.Eyeshot library for all CAD data processing, visualization, and interaction.
  • Inspection Modes: Supports probe and scanner planning, simulation, verification, and export workflows.
  • Planning Support: Uses shell generation, collision-aware routing, scan verification, path editing, and multi-part session persistence.
  • Configuration: Uses XML-backed scanner presets, color tolerances, tool assignments, and protected runtime settings.

Technical Details

This section provides key technical information for developers looking to build, run, and contribute to the project.

System Requirements

  • Operating System: Windows 10/11 x64.
  • IDE: Microsoft Visual Studio 2022 (recommended).
  • SDK: .NET 8 SDK or Runtime.
  • CAD Control: devDept Eyeshot Ultimate license.
  • Package Sources: Access to the SARKKIS proprietary NuGet packages used by the project.

Core Dependencies

The project relies on several key external and internal libraries:

  • ColorNamesSharp (1.0.0): A utility library for working with color names.
  • devDept.Eyeshot.Control.Wpf (2025.3.457): A high-performance 3D CAD control for .NET WPF applications. This is a commercial library, and a valid license is required for development and compilation. The project must be able to resolve the references to its assemblies.
  • Microsoft.Xaml.Behaviors.Wpf (1.1.135): Provides a set of useful behaviors for WPF applications.
  • SARKKIS.Utilities (3.6.2): A custom utility library from SARKKIS Robotics.
  • SARKKIS.WPFTools (2.12.4): A custom WPF tools library from SARKKIS Robotics.
  • .NET 8 & WPF: The application is built using the .NET 8 framework and Windows Presentation Foundation (WPF) for the user interface.
  • Doxygen: The tool used to generate this documentation. A local installation is required to run the documentation generation script.
  • Graphviz (Optional): To generate class diagrams and other graphs within the documentation, Graphviz must be installed and accessible from the system's PATH.

Building the Project

  1. Clone the Repository: Get a local copy of the source code.
  2. Install Dependencies: Ensure the .NET 8 SDK and Visual Studio 2022 are installed.
  3. Install Eyeshot: Make sure you have a licensed version of devDept Eyeshot Ultimate installed on your machine.
  4. Open the Solution: Launch the HirEV_SmartFitSystemsApp.sln file in Visual Studio.
  5. Restore NuGet Packages: Visual Studio should automatically restore the standard NuGet packages upon opening the solution.
  6. Build: Build the solution (Ctrl+Shift+B). The primary output executable will be located in the HirEV_SmartFitSystemsApp/bin/Debug (or Release) directory.

Generating Documentation

This documentation is generated using Doxygen. To regenerate it:

  1. Ensure Doxygen is installed and its location is in your system's PATH environment variable.
  2. For full diagram support, ensure Graphviz is also installed and in the PATH.
  3. Execute the generate_docs.bat script located in the project's root directory.
  4. The script will process the source code and open the main page of the generated documentation in your default web browser.
