Descrição detalhada

Main application window for HirEV SmartFitSystems.

Provides the main UI shell including:

  • 3D CAD model viewport (Eyeshot Design control)
  • TreeView for face/hole navigation with custom scroll handling
  • Side panels for different workflow stages
  • Window dragging and maximize/restore functionality

HirEV_SmartFitSystemsApp.MainWindow.MainWindow ( )

Initializes the main window and sets up the application environment.

Initialization sequence:

  1. Shows splash screen
  2. Sets decimal separator to period for consistent numeric formatting
  3. Creates and binds MainViewModel
  4. Waits for Eyeshot Design control to load before hiding splash screen
Excepções
ExceptionDisplays error dialog and closes application if initialization fails
