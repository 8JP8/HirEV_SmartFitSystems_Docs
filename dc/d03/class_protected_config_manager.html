Descrição detalhada

Manages a protected configuration file, encrypting and decrypting sensitive settings.

Uses AES-256 encryption to secure sensitive configuration data including:

  • Machine IP Address for CMM connection
  • Operator tolerance thresholds for quality control

Configuration is stored in AppData%/SKK_HirEV_SmartFitSystemsApp_Data/ProtectedConfig.dat
