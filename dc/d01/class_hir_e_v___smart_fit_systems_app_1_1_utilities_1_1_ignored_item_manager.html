◆ ReindexParentEntities()

void HirEV_SmartFitSystemsApp.Utilities.IgnoredItemManager.ReindexParentEntities ( IReadOnlyDictionary< int, int > indexMap)

Remaps stored ParentEntityIndex values after entities have been added to or removed from _designControl.Entities. Call this any time entities are inserted or removed at an index at or before an entity that owns ignored/flipped overlays - e.g. after removing a PART_ORIGIN BlockReference or a Grid-associated entity during a "move to origin" operation. Without this, overlay data silently points at the wrong (shifted) entity index and gets filtered out as "not visible" by SyncVisibility.

Parâmetros
indexMapMaps each OLD parent entity index that may appear in stored overlay data to its NEW index in _designControl.Entities. Omit an old index (or map it to -1) to mean "this entity was removed" - any overlay data for it is dropped.
