◆ InitializeOnFirstRun()

void SecurePasswordManager.InitializeOnFirstRun ( )
static

Initializes the password system on first application run.

Checks Windows Registry to detect first run by comparing timestamps in two registry keys:

  • Eyeshot license activation timestamp
  • Application initialization timestamp

If timestamps don't match or are missing, this is considered a first run and:

  1. Creates synchronized timestamps in both registry locations
  2. Generates a default password ("SKK") if no password file exists

Only runs on Windows OS platform.
