Descrição detalhada

Fast segment collision validator that checks path segments against a pre-built part mesh. Uses AABB (bounding box) pre-filtering + Möller-Trumbore ray-triangle intersection for fast collision detection.

Configuration (App.config):

  • PathPlanning_EnableSegmentCollisionValidation: Enable/disable validation
  • PathPlanning_SegmentCollisionSamplePoints: Number of sample points per segment
  • PathPlanning_MaxAlternativePathAttempts: Max attempts to find alternative path
