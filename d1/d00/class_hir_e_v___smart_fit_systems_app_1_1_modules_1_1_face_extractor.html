Descrição detalhada

Class responsible for extracting faces and their geometric data from an Eyeshot EntityList. This class processes 3D entities (meshes, Breps) and extracts individual faces with their control points, key points, geometric properties, and type classification.

The extraction process includes:

  • Converting entities to Brep representation
  • Extracting control points and deduplicating them
  • Identifying corner points and centroids
  • Classifying face types (planar, cylindrical, spherical, etc.)
  • Computing face areas and geometric information Note: Measurement point generation is handled by PathManager after extraction for consistency.

List<(Point3D pt, int vertexIndex)> HirEV_SmartFitSystemsApp.Modules.FaceExtractor.ExtractCornerPointsWithIndices ( Brep brep,
Brep.Face face )
private

Extracts corner points from a face and maps them to their corresponding Brep vertex indices. This method traverses face loops and edges to identify unique vertices that form the corners of the face.

Parâmetros
brepThe parent Brep entity containing vertex data for index lookups.
faceThe face whose corner points should be extracted. Must have valid loops and segments.
Retorna
A list of tuples containing:
  • pt (Point3D): The 3D coordinates of each corner point
  • vertexIndex (int): The index of the vertex in the parent Brep's vertex array Returns an empty list if the face has no loops or edges.

The extraction process:

  1. Iterates through all loops in the face
  2. For each segment in each loop, extracts edge start and end point indices
  3. Uses a HashSet to ensure each vertex index appears only once
  4. Looks up the actual Point3D coordinates from the Brep's vertex array

This method handles closed loops correctly by automatically deduplicating shared vertices.

Extracts comprehensive geometric data from a single Brep.Face. This method processes control points, corner points, centroid, face type, area, and color.

Parâmetros
brepThe parent Brep entity containing the face. Used for bounding box filtering and vertex lookups.
faceThe specific face from the Brep to extract data from. Can be null (will result in minimal CADFace data).
indexThe global face index for uniquely identifying this face across all entities.
entityColorThe color of the parent entity. Used as fallback if the face doesn't have its own color.
Retorna
A CADFace object populated with:
  • Control points (deduplicated and filtered)
  • Key points (corners and centroid)
  • Face type classification (planar, cylindrical, etc.)
  • Geometric information (radius, axis, etc. based on type)
  • Face area
  • Face color (prefers face color, falls back to entity color)

Control point extraction includes:

  • Conversion to surface representation
  • Deduplication using 3-decimal precision
  • Filtering points outside Brep bounding box (with 1mm tolerance)
  • Consistent ordering (Z, then X, then Y)

If control point extraction fails, an empty list is assigned for robustness.

◆ ExtractFaces()

List< CADFace > HirEV_SmartFitSystemsApp.Modules.FaceExtractor.ExtractFaces ( Action< int, int >? progressCallback = null,
System.Threading.CancellationToken cancellationToken = default )

Iterates through all entities, converts them to Brep if necessary, and extracts each face with its geometric data. This is the main extraction method that processes all entities and their faces sequentially. Progress updates are throttled to a maximum of one update every 50ms to avoid overwhelming the UI thread.

Parâmetros
progressCallbackOptional callback action for progress updates. Receives two parameters:
  • percentage (int): Progress percentage from 0-100 based on entities processed
  • faceCount (int): Total number of faces extracted so far Updates are throttled to prevent excessive UI thread invocations.
Retorna
A list of CADFace objects containing extracted geometric data for each face, including control points, key points, face type, area, and color information. Returns an empty list if no valid faces are found.

The method performs the following steps for each entity:

  1. Converts the entity to Brep representation if needed
  2. Rebuilds the Brep to ensure tessellation data is available
  3. Extracts each face and its geometric properties
  4. Reports progress periodically (maximum every 50ms)

Progress reporting is optimized with throttling to balance responsiveness and performance. The last entity always triggers a progress update to ensure 100% completion is reported.

◆ GetFaceArea()

double HirEV_SmartFitSystemsApp.Modules.FaceExtractor.GetFaceArea ( Brep.Face face)
private

Computes the total surface area of a face by summing the areas of all its parametric surfaces. The area calculation uses the Eyeshot GetArea method on tessellated parametric representations.

Parâmetros
faceThe face to compute area for. Must have parametric surface data.
Retorna
The total surface area in square millimeters (or current model units). Returns double.NaN if the face has no parametric data or if area calculation fails.

The method:

  1. Checks if parametric data exists (returns NaN if not)
  2. Iterates through all parametric surfaces in the face
  3. Regenerates tessellation if needed (tolerance 0.01)
  4. Sums the area of each surface using GetArea
  5. Ignores calculation errors for individual surfaces (robustness)

This approach handles complex faces composed of multiple surface patches.

◆ GetFaceCentroid()

Point3D? HirEV_SmartFitSystemsApp.Modules.FaceExtractor.GetFaceCentroid ( Brep.Face face)
private

Computes an approximate centroid (geometric center) of a face by averaging all tessellated vertices. This provides a representative center point for the face, useful for visualization and analysis.

Parâmetros
faceThe face to compute the centroid for. Must have parametric surface data with vertices.
Retorna
A Point3D representing the centroid (average position) of all tessellated vertices. Returns null if the face has no parametric data or no vertices after tessellation.

The computation:

  1. Collects all vertices from all parametric surfaces in the face
  2. Regenerates tessellation if needed (tolerance 0.01)
  3. Calculates the average X, Y, and Z coordinates

This is an approximation based on tessellation density. For analytical surfaces (planes, cylinders), the true centroid might differ slightly from this vertex-based average, but the difference is typically negligible for well-tessellated meshes.

Vector3D HirEV_SmartFitSystemsApp.Modules.FaceExtractor.GetFaceNormalApprox ( Brep.Face face)
private

Computes an approximate surface normal vector for a face using cross product of vectors formed by tessellated vertices. This heuristic method finds the first valid triangle in the tessellation to calculate a representative normal.

Parâmetros
faceThe face to compute the normal for. Must have parametric surface data with vertices.
Retorna
A normalized Vector3D representing the approximate surface normal direction. Returns a zero vector (0, 0, 0) if:
  • The face has no parametric data
  • The face has fewer than 3 vertices
  • No valid triangle can be formed (all points are collinear)
  • An error occurs during calculation

The algorithm:

  1. Collects all tessellated vertices from parametric surfaces
  2. Regenerates tessellation if needed (tolerance 0.01)
  3. Finds the first three non-collinear points (forms a valid triangle)
  4. Computes cross product: (B-A) � (C-A)
  5. Normalizes the resulting vector to unit length

The method skips duplicate points to ensure a valid triangle. Only calculates one normal (doesn't average across the entire face). For non-planar faces, this represents the normal at one local region.

FaceTypeEnum HirEV_SmartFitSystemsApp.Modules.FaceExtractor.InferFaceType ( object surface,
out string geometricInfo )
private

Infers the face type by checking the surface runtime type and extracts relevant geometric information. This heuristic method uses pattern matching to classify surfaces into standard geometric types.

Parâmetros
surfaceThe surface object to analyze. Can be any Eyeshot surface type (SphericalSurf, CylindricalSurf, etc.) or null.
geometricInfoOutput parameter containing geometric information specific to the surface type:
  • Spherical: "Radius: X.XX"
  • Cylindrical: "Radius: X.XX, Axis: (X, Y, Z)"
  • Conical: "Radius: X.XX, Angle: X.XX�"
  • Toroidal: "Major R: X.XX, Minor R: X.XX"
  • NURBS: "NURBS Surface"
  • Revolved: "Axis: (X, Y, Z)"
  • Tabulated: "Direction: (X, Y, Z)"
  • Planar: "Normal: (X, Y, Z)"
  • Unknown/Error: "N/A"
Retorna
A FaceTypeEnum value classifying the surface type. Returns FaceTypeEnum.Unknown if the surface is null, unrecognized, or if an error occurs during analysis.

The method uses runtime type checking (pattern matching) to identify the surface type. Supported surface types include: Spherical, Cylindrical, Conical, Toroidal, NURBS, Revolved, Tabulated, and Planar.

Geometric information is formatted with 2 decimal places for readability. Errors during type inference are caught and logged to Debug output, returning Unknown type.

Determines whether two 3D points are equal within a specified tolerance. This is useful for comparing floating-point coordinates with numerical precision tolerance.

Parâmetros
p1The first point to compare.
p2The second point to compare.
tolThe tolerance value for comparison (default 1e-9). Points are considered equal if the absolute difference in each coordinate (X, Y, Z) is less than this tolerance value.
Retorna
true if the Euclidean distance in each dimension (X, Y, Z) is less than the tolerance; false otherwise.

This method performs component-wise comparison rather than computing actual Euclidean distance, which is more efficient and sufficient for most equality checks. The default tolerance of 1e-9 is appropriate for millimeter-precision CAD models.

◆ TryConvertToBrep()

Brep? HirEV_SmartFitSystemsApp.Modules.FaceExtractor.TryConvertToBrep ( Entity e)
private

Attempts to convert an arbitrary Eyeshot Entity to Brep representation using reflection. This method dynamically invokes the ConvertToBrep method if it exists on the entity type.

Parâmetros
eThe entity to convert. Can be any Eyeshot Entity subclass (Mesh, BlockReference, etc.).
Retorna
A Brep object if conversion succeeds, or null if:
  • The entity type doesn't have a ConvertToBrep method
  • The ConvertToBrep method throws an exception
  • The conversion returns null

This method uses reflection to support conversion of any entity type that implements ConvertToBrep, without requiring explicit type checking for each entity type.

Common entity types that support ConvertToBrep:

  • Mesh
  • BlockReference
  • Some custom entity types

Entities that are already Breps are handled before calling this method (direct cast).

Conversion errors are logged to Debug output for troubleshooting but don't throw exceptions, allowing the extraction process to continue with other entities.
