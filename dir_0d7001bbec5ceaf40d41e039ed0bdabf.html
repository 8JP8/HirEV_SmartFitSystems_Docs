CMM Head & Probe Montages Library (v0.0.37)

This directory contains definitions, configuration files, and 3D CAD models for Coordinate Measuring Machine (CMM) motorized/manual heads and probe tip assemblies. It drives forward kinematic chain simulation, DMIS 5.3 sensor definitions, and the Probe Approach Optimizer (PAO) introduced in v0.0.37.

Directory Overview

Each subfolder represents a concrete CMM tool montage. In addition, the shared Renishaw_CAD_Library/ provides standard head bodies, probe sensors, modules, and ruby styli used to compose assemblies:

Cmm_Montages/
├── Renishaw_CAD_Library/ # Shared master CAD library
│ ├── Heads/ # PH10M, PH20 STEP models (mated & isolated)
│ ├── Probes/ # TP20 body, TP20 SF/EM1/EM2 modules, TP200, SP25M
│ └── Ruby_Styli/ # M2/M3 styli (1x10mm up to 5x50mm) and extensions (10-100mm)
│
├── PH10M_TP20/ # Standard Renishaw PH10M with TP20 & 20mm stylus
│ ├── MontageConfig.xml # Kinematic chain, angle limits, pivot offsets, DMIS label
│ ├── Head.stp # Head body CAD model (mounted to CMM Z-ram)
│ └── Tip.stp / Tip.stl # Articulated probe + stylus sub-assembly
│
├── PH10M_TP20_3x30/ # PH10M + TP20 with Ø3mm x 30mm stylus
├── PH10M_TP20_EM1_3x30/ # PH10M + TP20 EM1 (50mm extension module) + Ø3x30mm stylus
├── PH10M_TP20_EM2_4x50/ # PH10M + TP20 EM2 (100mm extension module) + Ø4x50mm stylus
├── PH10M_TP20_SE20_3x30/ # PH10M + TP20 + 20mm extension bar + Ø3x30mm stylus
├── PH10M_TP200_.../ # PH10M with high-accuracy strain-gauge TP200 assemblies
├── PH10M_SP25M_.../ # PH10M with SP25M scanning probe assemblies
├── PH20_TP20_.../ # Renishaw PH20 5-axis continuous articulating head assemblies
└── Custom_Head_Probe/ # User-defined custom head and probe configurations

Montage Configuration Schema (MontageConfig.xml)

Every montage folder includes a MontageConfig.xml that parameterizes the tool kinematics, physical dimensions, and DMIS mapping:

<?xml version="1.0" encoding="utf-8"?>
<CmmMontageConfig xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance" xmlns:xsd="http://www.w3.org/2001/XMLSchema">
<MontageName>PH10M_TP20</MontageName>
<Description>Renishaw PH10M indexing head with TP20 probe module and 20mm stylus</Description>
<HeadModelFile>Head.stp</HeadModelFile>
<TipModelFile>Tip.stp</TipModelFile>
<AttachmentOffsetX>0.0</AttachmentOffsetX>
<AttachmentOffsetY>0.0</AttachmentOffsetY>
<AttachmentOffsetZ>-45.0</AttachmentOffsetZ>
<PivotOffsetB>-5.0</PivotOffsetB>
<PivotOffsetA>-25.0</PivotOffsetA>
<TipContactOffsetX>0.0</TipContactOffsetX>
<TipContactOffsetY>0.0</TipContactOffsetY>
<TipContactOffsetZ>-59.2</TipContactOffsetZ>
<RubyBallRadius>1.0</RubyBallRadius>
<AxisAMin>0.0</AxisAMin>
<AxisAMax>105.0</AxisAMax>
<AxisAStep>7.5</AxisAStep>
<AxisBMin>-180.0</AxisBMin>
<AxisBMax>180.0</AxisBMax>
<AxisBStep>7.5</AxisBStep>
<TargetDmisSensorLabel>PH10M_TP20</TargetDmisSensorLabel>
<DefaultRackSlot>1</DefaultRackSlot>
</CmmMontageConfig>

Parameter Reference

Parameter Type / Units Description
MontageName string Unique identifier matching the folder name and tool assignment catalog.
HeadModelFile filename CAD file (.stp, .step, .stl) for the stationary head body mounted on the CMM quill.
TipModelFile filename CAD file (.stp, .step, .stl) for the articulating wrist and stylus sub-assembly.
AttachmentOffsetZ mm Vertical distance from CMM quill flange to head mounting datum.
PivotOffsetB mm Z-offset for the B-axis (Yaw / Azimuth rotation about Z).
PivotOffsetA mm Z-offset for the A-axis (Pitch / Inclination rotation about local X).
TipContactOffsetZ mm Distance from the A-axis pivot center to the ruby ball center.
RubyBallRadius mm Calibrated radius of the spherical contact tip (used in tip radius compensation).
AxisAMin / AxisAMax degrees Inclination angle limits (e.g., 0.0° to 105.0° for PH10; up to 115.0° for PH20).
AxisAStep / AxisBStep degrees Angular indexing resolution (7.5° for discrete Hirth joint heads; 0.0° for continuous 5-axis heads).
TargetDmisSensorLabel string Symbolic label emitted in DMIS S(name)=SNSDEF/... statements.
DefaultRackSlot integer Default slot number assigned in tool changing racks (e.g., MCR20, SCR200, FCR25).

Parametric CAD Fallback

If HeadModelFile or TipModelFile is omitted or missing from a montage folder, the application dynamically generates parametric Eyeshot 3D CAD geometry matching the offsets, shank diameters, and ruby ball radius defined in MontageConfig.xml.

Integration with v0.0.37 Path Planning & PAO

In version 0.0.37, montages defined in this directory are directly coupled with the core planning algorithms:

  1. Probe Approach Optimizer (PAO): The application resolves the active tool montage via CmmStandardToolCatalog.ResolveToolMontage(toolName) and constructs a ProbeHeadKinematicsConfig. The optimizer uses the head's mechanical properties (indexable vs. continuous, indexing step, unlock/lock latency, angular velocity) to sequence measurement waypoints and cluster features by iso-orientation, minimizing head rotations.
  2. Standardized Angle Limits: When converting surface normals to discrete (A, B) wrist angles (ProbeAngleStandardizer), the planner uses the montage's exact AxisAStep, AxisBStep, and AxisAMax instead of generic fallbacks.
  3. ANSI/DMIS 5.3 Code Generation: The post-processor pulls the montage's TargetDmisSensorLabel and DefaultRackSlot to emit accurate SNSDEF, SNSLCT, THLDEF, and WRIST statements.
  4. Kinematic Collision Checking: The multi-body forward kinematics assembly loads the exact 3D solid meshes from this directory for collision verification against part geometry.
