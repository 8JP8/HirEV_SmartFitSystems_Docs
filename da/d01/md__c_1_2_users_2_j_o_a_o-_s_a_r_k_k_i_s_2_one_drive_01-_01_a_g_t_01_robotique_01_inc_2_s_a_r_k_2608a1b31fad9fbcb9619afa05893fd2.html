CMM Setup & Calibration Guide for DMIS 5.3 Inspection Programs

This guide outlines the complete operational setup, hardware calibration, and configuration workflow for executing ANSI/DMIS 5.3 inspection programs generated by Hi-rEV SmartFitSystems on compatible Coordinate Measuring Machines (CMMs).

1. Supported CMM Controllers & DMIS Compatibility

The post-processor emits standards-compliant ANSI/DMIS 105.3-2016 instructions (.dmi / .dmis). Compatible CMM execution software packages include:

  • Hexagon PC-DMIS (CMM & NC-Gage)
  • Renishaw MODUS (UCC1/UCC2/UCC5 controllers)
  • Zeiss CALYPSO (via DMIS Import Engine)
  • Mitutoyo MCOSMOS (via DMIS Post/Import Module)
  • Metrologic Metrolog X4
  • LK Metrology CAMIO
  • Coord3 / Nikon Metrology CMM-Manager

2. Machine Volume & Workspace Configuration in App.config

The physical stroke limits and safety clearances of the CMM must be aligned between App.config and the machine physical granite bed.

Purpose & Parameter Descriptions

Parameter Setting Description
CMM_BoundingBox_Size_X/Y/Z Stroke (mm) Usable machine volume, SafeClearanceZ, and home position.
PathPlanning_AvoidBottomFace True Prevents measuring bottom faces resting on fixture or table.
PathPlanning_BaseAvoidanceHeight 15.0 mm Height clearance envelope maintained above machine table.
PathPlanning_BaseAvoidanceAngle 30.0 deg Minimum approach angle when measuring lower side walls.
Coordinates_RelativeToPart True Emits path points in Part Coordinate System (PCS).

3. Tool Changing Rack Calibration (Probe Changer)

Overview

In the generated DMIS program, tool changes are emitted as:

THLDEF/SGS(Tool1_GRP), 1
S(Tool1)=SNSDEF/BUILD, SW(PH10), SGS(Tool1_GRP)
...
SNSLCT/S(Tool1)

The DMIS code establishes the logical connection (associating probe assembly Tool1 with rack slot #1), but the physical 3D location, docking trajectory, and port coordinates must be calibrated directly inside the CMM manufacturer software.

Physical Rack Types

  • Renishaw MCR20 (TP20 magnetic stylus modules)
  • Renishaw SCR200 (TP200 high-accuracy modules)
  • Renishaw FCR25 (SP25M scanning modules/stylus holders)
  • Renishaw ACR1 / ACR3 (Autochange autojoint rack for heads/extensions)

Step-by-Step Rack Calibration Workflow

  1. Physical Mounting & Alignment:
    • Bolt the probe changer rack to the CMM granite bed outside the part fixturing envelope, but within mechanical XYZ travel limits.
    • Tram/align the rack parallel to either the X or Y machine axis using a dial indicator or manual probe touches (reduces docking collision risks).
  2. CMM Software Rack Definition:
    • Open the Tool Changer Setup / Probe Changer Wizard in your CMM software (e.g., Operation -> Calibrate/Edit -> Probe Changer in PC-DMIS, or Probe Rack Setup in MODUS).
    • Select the exact rack model (e.g., MCR20) and number of active ports (e.g., 3, 4, 6 ports).
  3. Port Position Calibration:
    • Mount a calibrated master probe (typically a standard 20 mm stylus) into the CMM head.
    • Run the automated Rack Calibration Routine:
      • Take reference touches on the datum port (Port 1 locating features or dedicated reference sphere on the rack).
      • The software determines the $(X, Y, Z)$ docking coordinates, clearance approach plane, and port pitch for all slots.
    • The software saves docking trajectory macros into the controller database.
  4. Slot Assignment Matching:
    • Assign each probe assembly to its designated slot:
      • Slot 1: Corresponds to DefaultRackSlot=1 defined in CmmStandardToolCatalog and each tool's MontageConfig.xml.
      • Slot 2..N: Assigned to additional styli or extensions.
    • Verify that the physical stylus in Slot $N$ matches the tool geometry configured in Hi-rEV SmartFitSystems.

4. Stylus Qualification & Reference Sphere Calibration

Before running inspection routines:

  1. Reference Sphere Setup:
    • Fix the qualification sphere (usually diameter 19.05 mm or 25.0 mm certified ruby sphere) securely to the granite table.
    • Qualify the master probe at $(A=0^\circ, B=0^\circ)$ to establish the reference datum center.
  2. Tip Qualification for Configured Head Angles:
    • The DMIS post-processor discretizes probe orientations to Renishaw PH10 steps ($7.5^\circ$ increments on A and B).
    • All $(A, B)$ angle combinations used in the generated inspection program must be qualified on the calibration sphere in the CMM software prior to execution to establish:
      • Effective ball diameter ($D_{\text{eff}}$ for 3D radius compensation PRCOMP/ON).
      • 3D tip center offset relative to the motorized wrist pivot point.

5. Part Fixturing & Datum Alignment (PCS Establishment)

Automated In-Program Calibration Routine

Hi-rEV SmartFitSystems automatically embeds a Part Position Calibration & Datum Verification routine in the DMIS program header when part bounding box data is present:

$$ AUTOMATED PART POSITION CALIBRATION & DATUM VERIFICATION ROUTINE
GOTO/CART,X_mid,Y_mid,Z_safe
F(CAL_TOP)=FEAT/POINT,CART,X_mid,Y_mid,Z_max,0,0,1
MEAS/POINT,F(CAL_TOP),1
PTMEAS/CART,X_mid,Y_mid,Z_max,0,0,1
ENDMES
$$ Lateral touches along -X, +X, -Y, +Y
...
$$ Establish Part Coordinate System (PCS) via 3-2-1 Alignment
DATDEF/F(CAL_TOP),DAT(A)
DATDEF/F(CAL_YMIN),DAT(B)
DATDEF/F(CAL_XMIN),DAT(C)
DATSET/DAT(A),ZDIR,ZORIG,DAT(B),YDIR,YORIG,DAT(C),XORIG
$$ Workpiece Position Evaluation
TOL/POS,CART,-2.0000,2.0000
EVAL/F(CAL_TOP)
EVAL/F(CAL_XMIN)
EVAL/F(CAL_YMIN)

Manual Fixturing Alignment (Alternative)

If your workpiece requires dedicated physical datums (e.g., machined dowel pins, tooling balls, planar primary datums):

  1. Clamp Workpiece: Mount the part on the CMM table using modular risers or toe clamps, ensuring the base avoidance boundary is respected.
  2. Execute Manual Alignment (in CMM Software):
    • Probe Datum A (Primary surface - Plane / Z level).
    • Probe Datum B (Secondary surface or two pins - Line / Axis rotation).
    • Probe Datum C (Tertiary surface or one pin - Point / Origin offset).
  3. Recall Alignment:
    • When importing the DMIS program, ensure the active PCS alignment corresponds to the part origin set in Hi-rEV (MovePartToOriginByDefault or CAD world origin).

6. Pre-Execution Dry Run Checklist

Always perform these verification steps before running an automated DMIS program at 100% feedrate:

  1. Home & Machine Limits: Verify that CMM_BoundingBox in App.config does not exceed the mechanical limit switches of the machine.
  2. Probe Changer Ready: Verify that all required probe assemblies are present in their correct rack ports and held magnetically without dirt or chips.
  3. Wrist Clearances: Confirm that the safe clearance plane (SafeClearanceZ) allows full PH10 motorized indexing ($A$ up to $105^\circ$) without contacting fixtures or the bridge.
  4. Simulation / Dry Run at Reduced Velocity:
    • Load the generated .dmi program into the CMM controller software.
    • Execute the program in Graphics Simulation Mode or on the physical machine at 10% manual override velocity with the operator holding the jog pendant E-stop.
  5. Datum Evaluation: Verify that the initial datum evaluation reports position deviation within permissible limits before automated feature touching commences.
