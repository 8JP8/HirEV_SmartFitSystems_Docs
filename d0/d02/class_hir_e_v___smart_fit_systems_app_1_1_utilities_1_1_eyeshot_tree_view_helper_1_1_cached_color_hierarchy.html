Descrição detalhada

Represents the complete pre-built UI hierarchy for a single color group.

Contains the color parent node and its two child group nodes (Faces and Holes), along with lists of all leaf nodes. This structure avoids recreating parent nodes during filtering operations, which is the key to the performance optimization.

When filtering, only the visibility of leaf nodes changes - the hierarchy structure remains intact.
