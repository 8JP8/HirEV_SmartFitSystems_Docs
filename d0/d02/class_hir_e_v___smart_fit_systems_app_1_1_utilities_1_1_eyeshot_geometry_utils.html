Descrição detalhada

Collection of utility methods for geometric operations with Eyeshot entities.

Provides comprehensive geometry utilities including:

  • Face type inference and geometric analysis (area, centroid, normal)
  • Ray-triangle intersection using Möller-Trumbore algorithm
  • Point projection and validation on face surfaces
  • Grid point generation for path planning
  • Vector operations (dot product, cross product, normalization)
  • Distance calculations (point-to-point, point-to-triangle, point-to-segment)

List< Point3D > HirEV_SmartFitSystemsApp.Utilities.EyeshotGeometryUtils.GenerateGridPointsOnFaceSurface ( Brep brep,
int faceIndex,
double gridSpacing,
double marginFromEdge,
int maxPoints,
List< Point3D >? existingControlPoints = null )
static

Generates auxiliary grid points on a face surface to supplement existing control points for path planning.

Parâmetros
brepThe Brep containing the face
faceIndexIndex of the face to generate points on
gridSpacingDistance between grid points in millimeters
marginFromEdgeMinimum distance from face edges in millimeters
maxPointsMaximum number of points to generate
existingControlPointsOptional list of existing control points to avoid (can be null)
Retorna
List of generated grid points that passed all filters

Algorithm:

  1. Determines the dominant plane (XY, YZ, or XZ) based on bounding box dimensions
  2. Creates a regular 2D grid in that plane
  3. Projects each grid point onto the face surface
  4. Filters out points that:
    • Are too close to existing control points (within gridSpacing)
    • Are too close to face edges (within marginFromEdge)
    • Cannot be projected onto the surface (projection distance > 10mm)

This method is used to ensure adequate coverage of large faces during CMM inspection path planning.

Vector3D HirEV_SmartFitSystemsApp.Utilities.EyeshotGeometryUtils.GetFaceNormalApprox ( Brep.Face? face)
static

Computes an approximate surface normal for a Brep face using tessellated vertices.

Parâmetros
faceThe Brep face to analyze (can be null)
Retorna
Normalized normal vector, or zero vector if computation fails or face is null

Algorithm:

  1. Collects all tessellated vertices from parametric surfaces
  2. Finds three non-collinear points from the vertex list
  3. Computes cross product of two edge vectors to get the normal
  4. Normalizes the resulting vector

This implementation uses manual cross product and normalization for compatibility with Eyeshot versions that don't expose Unitize/Cross/Length methods.

FaceTypeEnum HirEV_SmartFitSystemsApp.Utilities.EyeshotGeometryUtils.InferFaceType ( object? surface,
out string geometricInfo )
static

Infers the face type by analyzing the surface runtime type.

Parâmetros
surfaceThe surface object to analyze (can be null)
geometricInfoOutput parameter containing geometric details (e.g., "Radius: 10.5, Axis: (0, 0, 1)")
Retorna
The inferred face type enum value (Planar, Cylindrical, Spherical, Conical, Toroidal, BSpline, or Unknown)

Detects surface types by checking runtime type inheritance:

  • Plane → Planar (outputs normal vector)
  • CylindricalSurf → Cylindrical (outputs radius and axis)
  • SphericalSurf → Spherical (outputs radius)
  • ConicalSurf → Conical (outputs radius and half angle)
  • ToroidalSurf → Toroidal (outputs major and minor radii)
  • NurbsSurf → BSpline
