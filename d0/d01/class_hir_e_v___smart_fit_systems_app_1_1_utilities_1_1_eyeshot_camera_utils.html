Descrição detalhada

Provides camera control and automation utilities for the Eyeshot 3D viewport.

Features include:

  • Automatic camera following of probe during path simulation
  • Zoom-to-fit functionality for faces, holes, and vertices
  • Smooth camera transitions and viewport management

void HirEV_SmartFitSystemsApp.Utilities.EyeshotCameraUtils.AdjustCameraToViewProbe ( Point3D probePosition)
private

Adjusts camera position and target to center the probe in view.

Parâmetros
probePositionThe 3D position of the probe

Adjustment strategy:

  1. Sets camera target to the probe position
  2. Maintains camera distance at max of configured follow distance or 80% of current distance
  3. Preserves camera orientation (direction from which it views the target)

Logs the probe position to debug output for troubleshooting.

void HirEV_SmartFitSystemsApp.Utilities.EyeshotCameraUtils.CameraFollowTimer_Tick ( object sender,
EventArgs e )
private

Timer tick handler that updates camera position to follow the probe during simulation.

Parâmetros
senderEvent sender (DispatcherTimer)
eEvent arguments

Execution sequence:

  1. Searches for the probe tracking mesh on the "PROBE_TRACKING" layer
  2. Calculates the probe's center position
  3. Compares with last known position (movement threshold: 0.5mm)
  4. If probe moved significantly and is out of view, adjusts camera

List< Point3D > HirEV_SmartFitSystemsApp.Utilities.EyeshotCameraUtils.GetVerticesForFaces ( List< CADFace > faces)

Retrieves all tessellated vertices from a list of CADFaces.

Parâmetros
facesList of CADFaces to extract vertices from
Retorna
List of all vertices from all parametric surfaces of the faces

For each face:

  1. Retrieves the Brep entity from the design control
  2. Accesses the specific face via FaceIndex
  3. Iterates through parametric surfaces
  4. Regenerates vertices if needed (tessellation tolerance: 0.01)
  5. Collects all vertices into a single list

◆ IsPointInView()

bool HirEV_SmartFitSystemsApp.Utilities.EyeshotCameraUtils.IsPointInView ( Point3D point)
private

Checks if a point is within a reasonable viewing distance from the camera target.

Parâmetros
pointThe point to check (typically the probe position)
Retorna
True if the point is in view, false if camera should be adjusted

A point is considered "in view" if its distance from the camera target is less than 50% of the camera's distance from the target.

This ensures the probe stays reasonably centered in the viewport.

void HirEV_SmartFitSystemsApp.Utilities.EyeshotCameraUtils.LoadCameraFollowSettings ( )
private

Loads camera following settings from App.config.

Loads the following settings from App.config:

  • Simulation_CameraFollowDistance (default: 100.0mm)
  • Simulation_CameraViewMargin (default: 30.0mm)
  • Simulation_CameraBoundingBoxDistance (default: 150.0mm)
  • Simulation_CameraFollowEnabled (default: false)

If any setting fails to parse, all settings revert to defaults.

◆ ZoomToFace()

void HirEV_SmartFitSystemsApp.Utilities.EyeshotCameraUtils.ZoomToFace ( CADFace face)

Zooms the camera to fit a specific CADFace in the viewport.

Parâmetros
faceThe CADFace to zoom to

Zoom strategy:

  1. Retrieves all tessellated vertices from the face's parametric surfaces
  2. Creates a temporary PointCloud from these vertices
  3. Uses Eyeshot's ZoomFit to frame the PointCloud
  4. Removes the temporary PointCloud to keep the scene clean

Does nothing if face is null or references an invalid entity index.

void HirEV_SmartFitSystemsApp.Utilities.EyeshotCameraUtils.ZoomToHole ( CADHole hole)

Zooms the camera to fit all faces that constitute a hole.

Parâmetros
holeThe CADHole to zoom to

Zoom strategy for holes:

  1. Retrieves all CADFaces that belong to the hole via FaceGlobalIndices
  2. Collects vertices from all constituent faces
