Descrição detalhada

Generates an exterior offset shell mesh from part geometry for shell-constrained path planning. Supports multiple shell generation strategies:

  1. Face-offset shell: Offsets part face meshes outward by a fixed distance.
  2. ConvexHull shell: Builds a convex hull mesh from approach points using Eyeshot Utility.ConvexHull().
  3. Full Point Cloud shell: Creates a mesh using ALL approach points as vertices with Delaunay-like triangulation.

NOTE: ConvexHull only keeps outer boundary vertices. For parts with concave features, use BuildFullPointCloudShell() which preserves ALL approach points as mesh vertices.

HashSet< int > holeFaceIndices,
IList< Point3D >? approachPoints = null,
HashSet< int >? flippedFaceIndices = null )

Builds a shell by offsetting the part's exterior surfaces outward. This method:

  1. Uses Eyeshot's Surface.Offset() to create offset surfaces for each face
  2. Tessellates offset surfaces to create the shell mesh
  3. Excludes hole faces to automatically "close" holes in the shell

This creates a uniform offset shell that perfectly covers the original part.

Parâmetros
partBrepThe original part BREP to offset
holeFaceIndicesSet of face indices belonging to holes (to exclude from shell)
approachPointsOptional: approach points for validation
flippedFaceIndicesOptional: Set of face indices whose normals have been manually flipped by user
Retorna
Shell mesh (only tessellated if needed), or null if failed
