Descrição detalhada

Validates approach points against the SDF shell mesh. Core rule: no approach point may sit more than half the shell offset INSIDE the shell surface (i.e. SDF value < -offsetDistance/2). Points that violate this are extended along their existing measurement-to-approach direction.

◆ ValidateAndCorrectApproachPoints()

int HirEV_SmartFitSystemsApp.Utilities.Algorithms.PathVolumeValidator.ValidateAndCorrectApproachPoints ( List< ApproachMeasurementPair > pairs,
double tolerance = 1::5 )

Validates and corrects approach points so that none sits more than half the shell offset distance inside the shell mesh surface.

Correction strategy:

  1. Query SDF value at the approach point.
  2. If sdf < (offsetDistance / 2) → point is too close to or inside the shell.
  3. Extend the point from its measurement target along the stored face normal.
  4. Reject the pair when that normal line cannot reach the required clearance.
