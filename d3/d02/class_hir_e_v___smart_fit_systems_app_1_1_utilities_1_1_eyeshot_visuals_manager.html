Descrição detalhada

Manages creation, display, and removal of temporary visual markers in the Eyeshot 3D viewport.

Provides visual feedback for user interactions and geometry analysis including:

  • Control Point Spheres: Blue spheres showing measurement points on faces
  • Corner Markers: Yellow cubes highlighting face vertices and corners
  • Hole Indicators: Pink spheres at hole centers with depth visualization
  • Hover Highlights: Temporary markers showing geometry under the mouse cursor
  • Face Highlights: Temporary color overlays for selected faces

Performance: Uses async Task.Run for marker generation to keep UI responsive. Markers are cached in lists for batch clearing operations.

void HirEV_SmartFitSystemsApp.Utilities.EyeshotVisualsManager.ShowCornerMarkersForFace ( CADFace face,
int highlightVertexIndex = -1 )

Displays yellow cube markers at all corner points of a CADFace.

Parâmetros
faceThe CADFace to show corner markers for
highlightVertexIndexOptional vertex index to highlight with a larger, brighter cube (default: -1 = no highlight)

Creates cube markers at each keypoint with PointType.Corner.

If highlightVertexIndex is specified, that corner gets a larger cube (1.8x size) with a brighter orange color.

Uses Task.Run for async generation to maintain UI responsiveness.

Automatically clears any existing corner markers before displaying new ones.
