Propriedades

bool AvoidBottomFace = false [get, set]
 When true the scanner never dips below BottomAvoidanceAngleDeg elevation above the part's bottom plane. Mutually exclusive with ScanBottomFace.
double BottomAvoidanceAngleDeg = 30.0 [get, set]
 Minimum elevation angle (°) above the part's bottom plane when AvoidBottomFace is true. Default 30° keeps the CMM arm clear of the fixture.
bool ScanBottomFace = false [get, set]
 When true (and AvoidBottomFace is false) the planner includes nadir positions so the bottom face is fully covered via the spherical orbit.
bool UseSimpleOrbitalRadius = false [get, set]
 When true, keeps the legacy orbit radius: part radius + scanner optimal standoff. When false, uses part radius + OrbitalPartClearanceOffset.
double OrbitalPartClearanceOffset = 150.0 [get, set]
 Clearance added to the farthest point from the part centroid to build the scanner orbit radius when UseSimpleOrbitalRadius is false.
bool ScanHoles = true [get, set]
 Detect cylindrical holes and inject axial scan passes that aim the scanner straight down each hole axis for complete bore coverage.
double HoleScanApproximationThreshold = 50.0 [get, set]
 Minimum threshold distance to approach holes, allowing the scanner to dive in closer than OptimalStandoff.
double MinHoleRadius = 3.0 [get, set]
 Minimum hole radius (mm) to consider for dedicated axial scanning.
int HoleScanRings = 4 [get, set]
 Number of radial scan rings inside each detected hole.
double MinCoveragePercent = 95.0 [get, set]
 Required surface coverage percentage (0–100).
int FibonacciSampleCount = 300 [get, set]
 Number of candidate positions on the Fibonacci sphere used as input to the greedy coverage algorithm. Higher → better coverage, slower.
int ArcWaypoints = 6 [get, set]
 Interpolation waypoints on each great-circle arc.
double FibonacciBaseRadius = 500.0 [get, set]
 Reference scanner-orbit radius used to scale Fibonacci sample count.
double FibonacciMinAmplification = 1.0 [get, set]
 Minimum multiplier applied to FibonacciSampleCount after part-size scaling.
double FibonacciMaxAmplification = 5.0 [get, set]
 Maximum multiplier applied to FibonacciSampleCount after part-size scaling.
bool AddRolledCandidates = true [get, set]
 When true, adds a second up-vector roll for each candidate pose.
bool AddAngledCandidates = true [get, set]
 When true, adds pitched/yawed candidate orientations for side/downward regions.
double AngledCandidateMaxUnitZ = 0.85 [get, set]
 Only add angled candidate variations when the candidate unit Z is below this value.
double[] AngledCandidateAnglesDeg = new[] { 20.0, 40.0 } [get, set]
 Angle variations in degrees used for extra pitched/yawed candidate orientations.
double HoleScanDepthFraction = 0.9 [get, set]
 Depth fraction used by hole ring targets. 0.9 keeps targets near, but not past, the bottom.
int HoleScanRadialCount = 4 [get, set]
 Number of radial positions around each hole-depth ring.
double HoleScanRadialOffsetFactor = 0.55 [get, set]
 Radial scanner offset as a multiplier of hole radius for bore-wall viewing.
double HoleScanBottomAvoidanceZTolerance = 0.5 [get, set]
 Z tolerance used by bottom-avoidance when filtering hole scan poses.
